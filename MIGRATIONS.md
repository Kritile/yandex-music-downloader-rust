# Переход между версиями

## После v4.0.0

- Токен можно передавать через `YANDEX_MUSIC_TOKEN`; прежний параметр `--token` сохранён и имеет приоритет над переменной окружения.
- Бинарники для Linux x86_64/aarch64, Windows x86_64 и macOS arm64/x86_64 публикуются в GitHub Release при отправке тега `v*`. Linux-сборки используют glibc.
- Загрузка треков остаётся последовательной; параметр `--jobs` не добавлен.

## v3.5.5 → v4.0.0

- Реализация перенесена с Python на Rust. Для сборки нужен Cargo; Python, `pip` и FFmpeg для запуска больше не нужны.
- Вместо `pip install` выполните `cargo install --path .` из корня репозитория либо соберите бинарник командой `cargo build --release`.
- Имя команды и прежние аргументы сохранены. Значения `--quality`, `--lyrics-format` и `--compatibility-level` не изменились.
- Старый пакет `ymd` удалён. Если вы импортировали его модули из Python, перейдите на запуск CLI.

## v3.2.0b0

При использовании `--unsafe-path` символы `/` и `\` заменяются на `_`. Если вы используете `--skip-existing` и у вас есть такие символы в названиях, некоторые элементы могут загрузиться повторно.

## v2 → v3

- Для авторизации используйте `--token`. Аргументы `--browser`, `--user-agent`, `--cookies-path` удалены; авторизация через cookies недоступна.
- Вместо `--hq` используйте `--quality 1`.
- `--disable-ipv6` удалён.
- Задержка между запросами по умолчанию равна нулю. Мобильный токен не требует прежнего значения `--delay`.
