# Правила работы с репозиторием

- Читайте `ARCHITECTURE.md` перед изменением потока загрузки, API или тегов.
- Сохраняйте имя команды и публичные флаги CLI. Изменения совместимости описывайте в `MIGRATIONS.md` и README.
- Не добавляйте в тесты реальные OAuth-токены, URL загружаемых файлов или личные данные.
- Проверяйте сетевые изменения локальными фикстурами; реальная загрузка требует токена и не входит в автоматический тестовый набор.
- Перед завершением выполняйте `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings` и `cargo test --all-targets`.
- Поддерживайте документацию на русском языке. В README должно сохраняться указание об использовании генеративного ИИ при переносе на Rust.

## Актуальная документация библиотек

Когда задача касается API, конфигурации или поведения конкретной библиотеки, SDK либо CLI, сначала получите актуальные сведения через Context7 CLI: `npx ctx7@latest library <название> "<точный вопрос>"`, затем `npx ctx7@latest docs <id> "<точный вопрос>"`. Для рефакторинга и логики программы без таких вопросов Context7 не нужен. Не передавайте токены и другие секреты в запросах к документации.
